📌 Projeto de Dimensionamento de Cabos Elétricos
📖 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de automatizar o processo de dimensionamento de cabos elétricos, tornando-o mais rápido, confiável e alinhado às normas técnicas.

A ideia surgiu a partir de uma necessidade real observada em ambiente profissional, onde o processo era realizado de forma manual, extensa e, muitas vezes, sujeito a erros ou inconsistências.

⚙️ Funcionalidades

O sistema realiza o dimensionamento com base nas seguintes informações fornecidas pelo usuário:

Dados do equipamento
Distância da fonte de alimentação
Seção do condutor (fio)

Com base nesses dados, o sistema:

✅ Calcula a queda de tensão
✅ Verifica se a instalação atende às normas
✅ Indica se a configuração está adequada ou se precisa de ajustes
🧠 Como funciona

O cálculo é realizado considerando critérios técnicos de dimensionamento elétrico, principalmente relacionados à queda de tensão.

A partir disso, o sistema consegue prever:

Se a ligação funcionará corretamente
Se haverá perda excessiva de energia
Se será necessário utilizar outro tipo de cabo ou configuração
🎯 Objetivo

Reduzir erros humanos, otimizar o tempo de análise e garantir maior confiabilidade no dimensionamento de instalações elétricas.

🚀 Possíveis melhorias

Simulação de diferentes cenários
